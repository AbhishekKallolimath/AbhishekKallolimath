# 🚀 What I'm Building

## 🔬 ResampleRank

### Meta-Learning for Imbalanced Tabular Classification

A research project investigating whether the characteristics of an imbalanced dataset can be used to **predict and rank effective resampling strategies for previously unseen datasets**.

### 🔍 Focus

- Dataset profiling
- Meta-feature extraction
- Imbalanced learning
- Resampling strategy evaluation
- Meta-learning
- Performance benchmarking

### 🧪 Techniques

`SMOTE` `ADASYN` `Random Oversampling` `SMOTE-ENN`

### 🐳 Deployment

The project has been containerized using Docker and published to Docker Hub.

## 🛠️ DevPilot

### Python CLI for Project Auditing & Developer Diagnostics

DevPilot is a Python-based command-line utility designed to help developers inspect and understand their projects through a single CLI.

### ⚡ Capabilities

```text
info      → Display project/tool information
check     → Run a quick project check
health    → View project health
version   → Show DevPilot version
doctor    → Check system/environment health
audit     → Audit the current project
scan      → Scan for potential secrets
stats     → Display project statistics

🐳 Dockerized Application
